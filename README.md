### 🌱 SoulUp — Avatar Inteligente e Sustentável
`Challenge FIAP 2026` · `Grupo Dome`

Rede social sustentável em que cada pessoa tem um avatar que evolui conforme realiza ações sustentáveis reais: missões geram Ecoa Points, o avatar sobe de nível, conquista selos e personaliza o visual na loja.

- 🕸️ **Front-end:** React + TypeScript + Tailwind, com simulador interativo do avatar → [ver site](https://soul-up-sprint-4.vercel.app/)
- ☕ **Back-end:** API RESTful em Java com Spring Boot e Oracle, publicada no Render
- 🐍 **Python:** CRUD em Oracle, consumo de API pública e exportação em JSON
